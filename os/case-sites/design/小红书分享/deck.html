边界 ①09 / 26
/ 边界 ① · 为什么会发生

模型塌陷，是怎么产生的？

模型塌陷是指生成模型由于

  • ①过度使用 低质量数据
  • ②对类似模型的输出进行 重复微调

而导致 性能下降 的现象。

退化表现为：输出多样性减少、泛化能力降低、超出训练分布的任务表现减弱。

低质量 AI 内容从哪里来？

SLOP

韦氏词典 2025 年度热词，意为「AI 泔水」。

/ 边界 ③

很多能力，
不是大模型
本身的能力。

大模型的底层逻辑是「下一个 Token 的概率预测」。
它不通过数学公式来计算，而是根据语料库判断 — 这串数字后面，最大概率出现的是什么。

边界 ③16 / 26
/ 边界 ③ · 拆解

它学到的是「语言」，没学到「能力」。

/ 学到了 · 语言
  • ✓怎么表达
  • ✓怎么解释
  • ✓怎么模仿推理
/ 没学到 · 能力
  • ✗真正的计算
  • ✗操作系统
  • ✗调用外部世界
/ 封闭系统

输入：文本 → 输出：文本

没有外部接口（无法作用世界）

/ 概率采样

不是确定计算，没有严格逻辑

数学会错 · 逻辑会漂 · 每次结果都不同

边界 ④19 / 26
/ 知道这些后

我就
不焦虑了。

AI 是 影子，
而你是 光源。

它的一切「智能」都锚定在人类产出的存量数据上。
它没法产生超越性的直觉，也没有对现实世界的切身感受。

真正让你不可替代的，不是处理信息的速度，
而是你对现实世界的 感知力，以及对逻辑真伪的 判断权。
