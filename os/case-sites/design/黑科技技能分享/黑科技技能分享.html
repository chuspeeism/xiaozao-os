FIG · 003 / HALFTONE
04 · Technique
Halftone fields.
把亮度映射成「点的直径」，让眼睛自己完成插值。
既是最老的印刷工艺，也是最便宜的 anti-alias。
1.  Luminance → radius
单通道映射，每个 cell 一个点；对比度由 cell 尺寸决定。
2.  Cell rotation = identity
15° / 45° / 75° 三色角度；单色时走 45°，视觉最稳。
3.  Moiré as feature
不消除摩尔纹；让它成为材质语言的一部分。
4.  Cost: O(1) per pixel
纯 fragment，无 pass，无 buffer。移动端 60fps 起步。

08 · Where it breaks
Not every signal
survives the noise.
CASE / 01
Fine type
< 14px.
阈值抖动会吞掉笔画——中文尤甚。
解决：局部关闭 dither，走 MSDF。
CASE / 02
Slow
motion.
静态抖动在 < 12 fps 下出现「爬虫感」。
解决：以帧号做时间扰动。
CASE / 03
HDR
surfaces.
高光被量化成大黑点，显得脏。
解决：亮度 > 0.92 时切回 raw。
